# St Martin's Duty Roster

Vite + React + Tailwind project for a collaborative weekly duty roster.

## Local development

1. npm install
2. npm run dev
3. open http://localhost:5173

## Deploy to Vercel (recommended)

1. Push this project to a GitHub repository.
2. Go to https://vercel.com, sign in and click "New Project" → Import from GitHub.
3. Select the repository and click Deploy. Vercel auto-detects Vite and uses the `npm run build` command.

Alternatively, run `vercel` from this folder using the Vercel CLI to deploy directly.
